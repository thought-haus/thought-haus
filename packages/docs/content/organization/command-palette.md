## Opening the Command Palette

Press `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) to open the command palette. A centered overlay appears with a search field, ready for you to start typing.

## Quick Note Switching

The command palette is the fastest way to jump to any note. Start typing and the palette shows matching notes in real time. Use the arrow keys to navigate results and press `Enter` to open the selected note.

The palette searches note titles using the same search engine that powers the main search — with prefix matching and fuzzy tolerance for typos.

## Keyboard Navigation

| Key | Action |
|---|---|
| `Cmd/Ctrl + K` | Open the command palette |
| `Escape` | Close the palette |
| `↑` / `↓` | Navigate through results |
| `Enter` | Open the selected note |

The palette is designed for keyboard-first use. You can find and open a note without touching the mouse: press `Cmd+K`, type a few characters, arrow to the result, and press `Enter`.

## How It Differs From Search

The command palette and the search field in the notes list both search your notes, but they serve different purposes:

| | Command Palette | Notes List Search |
|---|---|---|
| **Shortcut** | `Cmd/Ctrl + K` | Click the search field |
| **Purpose** | Quick navigation | Browse and filter results |
| **Behavior** | Opens selected note immediately | Filters the notes list |
| **UI** | Centered overlay | Inline in notes list |

Use the command palette when you know which note you want and just need to get there fast. Use the notes list search when you want to browse results and explore.

## Tips

- The command palette is especially useful when you have many notes and scrolling through the sidebar would be slow.
- You only need to type a few characters — the fuzzy matching usually finds the right note with 3-4 keystrokes.
- The palette remembers no state between opens — it always starts fresh with an empty search field.
