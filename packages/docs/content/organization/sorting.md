## Sort Modes

The notes list can be sorted in three ways:

### Date Modified

Sorts notes by their last modification time. Recently edited notes appear first (in descending order) or last (in ascending order). This is the default sort mode — it keeps your active notes at the top.

### Date Created

Sorts notes by their creation time. This is useful when you want to see your notes in chronological order regardless of when they were last edited.

### Title

Sorts notes alphabetically by their title. Useful when you're looking for a specific note by name or want a stable, predictable ordering.

## Sort Direction

Each sort mode can be applied in two directions:

- **Descending** — Newest first (for dates) or Z-A (for titles). This is the default.
- **Ascending** — Oldest first (for dates) or A-Z (for titles).

Toggle the sort direction by clicking the sort direction control in the notes list header.

## Changing the Sort Mode

Use the sort controls in the notes list header to switch between sort modes. Your selection is persisted across sessions, so the app remembers your preferred sorting the next time you open it.

## Sorting and Filters

Sorting works in combination with other filters. When you filter by tag or search query, the filtered results are displayed in your chosen sort order. This lets you browse, for example, all notes tagged `work` sorted by most recently modified.

## Tips

- **Date Modified** is best for daily use — your active notes bubble to the top naturally.
- **Date Created** is useful for reviewing notes in the order you wrote them, like a chronological journal.
- **Title** sorting helps when you have a large collection and want to find a note by name without using search.
