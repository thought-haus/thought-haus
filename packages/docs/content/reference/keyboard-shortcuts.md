## Global Shortcuts

These work anywhere in the app:

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + N | Create a new note |
| Cmd/Ctrl + K | Open the command palette |
| Cmd/Ctrl + \\ | Toggle the sidebar |
| Cmd/Ctrl + Shift + A | Toggle the AI assistant panel |
| Cmd/Ctrl + , | Open Settings |
| Cmd/Ctrl + Shift + F | Toggle favorite on the current note |

## Command Palette

When the command palette is open:

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + K | Select all text in the search field |
| Escape | Close the palette |
| Arrow Down / Ctrl + N / Ctrl + J | Move highlight down |
| Arrow Up / Ctrl + P / Ctrl + K | Move highlight up |
| Enter | Open the highlighted note |

## Editor

Standard TipTap/ProseMirror editing shortcuts apply:

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + B | Bold |
| Cmd/Ctrl + I | Italic |
| Cmd/Ctrl + Shift + X | Strikethrough |
| Cmd/Ctrl + E | Inline code |
| Cmd/Ctrl + Shift + 7 | Ordered list |
| Cmd/Ctrl + Shift + 8 | Bullet list |
| Cmd/Ctrl + Shift + 9 | Task list |
| Cmd/Ctrl + Shift + B | Blockquote |
| Cmd/Ctrl + Alt + 1–6 | Heading level 1–6 |
| Cmd/Ctrl + Z | Undo |
| Cmd/Ctrl + Shift + Z | Redo |

### Note Links

| Shortcut | Action |
|---|---|
| `[[` | Open note link autocomplete |
| Arrow Down / Arrow Up | Navigate suggestions |
| Enter | Insert selected note link |
| Escape | Dismiss suggestions |

### Links

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + Click on link | Open URL in new tab |
| Click on link | Show link edit popover |

### Properties

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + ; | Add a new property |
| Enter / Tab | Confirm property key, move to value |
| Enter | Save property value |
| Escape | Cancel editing |
| Cmd/Ctrl + Backspace | Delete the property being edited |

## Notes List

When the search field is focused:

| Shortcut | Action |
|---|---|
| Escape | Clear search and blur |
| Arrow Down / Ctrl + N / Ctrl + J | Move highlight down |
| Arrow Up / Ctrl + P / Ctrl + K | Move highlight up |
| Enter | Open the highlighted note |

## Tags

When editing a tag:

| Shortcut | Action |
|---|---|
| Enter | Add the tag |
| Escape | Cancel tag input |
| Arrow Down / Arrow Up | Navigate tag suggestions |

## Favorites

When a favorite item is focused:

| Shortcut | Action |
|---|---|
| Delete / Backspace | Remove from favorites |
| Ctrl + Arrow Up | Move favorite up |
| Ctrl + Arrow Down | Move favorite down |

## AI Assistant

| Shortcut | Action |
|---|---|
| Enter | Send message |
| Shift + Enter | New line |
| `/` | Show slash command suggestions |
| `@` | Show note mention suggestions |
| Arrow Down / Arrow Up | Navigate suggestions |
| Enter | Select suggestion |
| Escape | Dismiss suggestions |

## Web Clipper

| Shortcut | Action |
|---|---|
| Ctrl/Cmd + Shift + S | Open clipper popup |
| Alt + Shift + S | Quick clip |
